# Juandre Art Portfolio

Interactive portfolio site built with React, Vite, MUI, and shader-driven visuals.

Production runs on Vercel at https://ee-ze.com.

## Running Locally

Install dependencies and start the app:

```bash
pnpm install
pnpm dev
```

## Deployment

The site is deployed on Vercel with SPA routing configured in `vercel.json`.
